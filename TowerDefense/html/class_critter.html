Detailed Description

One critter: reward, hit points, strength, speed and level. Stats come from the type and the level (see the report). It finds the shortest path to the exit when it spawns and then follows it. Critter is Observable: spawning, moving to another cell, losing hit points, being slowed (and the slow wearing off), dying and escaping call notify(), so the attached observers (CritterObserver) re-display the critter.

◆ update()

void Critter::update ( double deltaTime,
const std::function< bool(int, int)> & isOccupied = nullptr )

Moves the critter along its path. isOccupied(row, column) tells whether another critter is on that cell. When it is, the critter waits just behind it until the cell is free, so a path cell never holds two critters (one game element per cell). The exit is never blocked: a critter that reaches it leaves the map. Without isOccupied the critter walks freely (used for a single critter).

Detailed Description

Decorator pattern (Assignment 3, Part 3): base class of every tower upgrade that can be added during play.

A TowerDecorator IS a Tower (so the game, the GUI and the observers use it like any other tower) and HAS a Tower: the wrapped tower, which it owns and deletes. Every Tower operation is forwarded to the wrapped tower, so a decorator that adds nothing behaves exactly like the tower it wraps. Concrete decorators override only what they change:

  • LevelUpDecorator: one level higher, +20% damage and range, +10% fire rate (stats)
  • SplashDecorator: damage also hits the critters around the target
  • BurningDecorator: the target keeps taking damage for a few seconds
  • FreezingDecorator: the target is slowed down

Decorators stack: new BurningDecorator(new SplashDecorator(new LevelUpDecorator(new BasicTower(1, 1)))). On each shot the innermost tower handles the cooldown and target selection, then calls applyAttack on the OUTERMOST decorator, which runs the wrapped attack first and then adds its own effect, all the way down the chain.

Mutating operations (purchase, upgrade, sell, moveTo, update) call notify() on the decorator after forwarding, so the observers attached to the decorator see the new state of the wrapped tower.

Price of the special upgrades, which can be bought once each, at any level.

Decorator pattern (Assignment 3, Part 3): the upgrades the player buys during a game.

Each helper checks the rules and the price, takes the coins, then wraps the tower in a new decorator: tower.reset(new SomeDecorator(tower.release())). The unique_ptr then owns the decorator, which owns the old tower, so the game and the GUI keep using the same std::unique_ptr<Tower> slot. Each helper returns false (and leaves the tower and the coins unchanged) when the upgrade is refused.
